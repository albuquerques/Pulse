# Mascote

As quatro expressões do mascote Pulse, uma por faixa da nota: baixa (sonolento, amassado), média (olhando de lado), alta (feliz, com mãos e bochechas) e perfeita (olhos de estrela, pulando). Desenhadas a partir da folha de construção do mascote, com as cores do tema claro: corpo `score-*-body`, base `score-*-shade`, traços `ink`, bochechas `blush` e efeitos em `lime-strong`. Cada figura tem 320 × 300 com sobra para topete e efeitos; o personagem ocupa o centro.
